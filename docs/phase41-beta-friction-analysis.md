# Phase 41 — Beta Friction Analysis

Phase 41 turns Phase 40's local beta evidence into a ranked, advisory fix queue.

## Signals analyzed

- average Fun and Clarity ratings
- time spent with the guided path incomplete
- repeated navigation across a small set of tabs
- multiple sessions without first judged mastery
- mastery without inspecting the resulting city change
- reaching retention without sampling broader engineering practice
- multiple sessions without a persistence confirmation

## Principles

1. Recommendations are evidence-driven and local-first.
2. High-impact activation and comprehension failures rank above cosmetic polish.
3. The analyzer never changes hidden tests, mastery, interview scores, rewards, difficulty, or economy values.
4. Recommendations are suggestions for the next implementation/tuning pass, not autonomous balance changes.

## Intended beta loop

Play → capture Fun/Clarity + guide/session events → review ranked friction → implement the highest-impact supported fix → test again.
