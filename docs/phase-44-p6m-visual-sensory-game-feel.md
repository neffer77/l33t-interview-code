# Phase 44 P6-M — Visual & Sensory Game Feel

P6-M makes technical accomplishments and civilization events visually unmistakable.

## Player-facing behavior

- Construction and upgrades pan the camera to the affected place and emit visible particle bursts plus callouts.
- Successful learning/city consequences celebrate with stronger bursts and building bounce feedback.
- Earned resources float over the world instead of changing only counters.
- Crises shake the camera and produce red incident effects.
- Legacy milestones receive a distinct monument-style celebration.
- Job offers and team missions reuse the same world-feedback language so existing systems feel like city events.

## Acceptance criterion

A player should be able to tell that something important happened without reading a dashboard number. Cause and effect must be visible in the world.
