# Phase 44 P6-F — Unified Civilization Status Dashboard

P6-F makes the existing-systems integration persistently visible in the City view.

## Visible domains

- Career: prestige, opportunity, confidence, recruiting visibility.
- Company: culture, execution, influence, alignment.
- Team: cohesion, mentorship, collaboration, momentum, synergy.
- World: resilience, legacy, narrative, stability, continuity.

The compact dashboard is always present in the City view, including when all values are zero. This makes the visual integration verifiable immediately after deployment. The panel can be expanded to show the full metric breakdown and most recent event for each domain.

## Balance

P6-F does not introduce new rewards, currencies, or progression gates. It only projects bounded 0–100 state produced by P6-B through P6-E. Those original consequence modules remain authoritative.

## Responsive behavior

Desktop places the dashboard in the upper-right of the city, opposite the learning navigator. Narrow/mobile layouts move it to a compact bottom overlay above the city controls. The expanded panel remains optional.
