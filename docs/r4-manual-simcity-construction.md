# R4 — Manual SimCity Construction Loop

R4 changes Codeopolis from an automatically seeded settlement into a player-authored city for genuinely fresh saves.

## Fresh-start contract

A virgin save begins on empty land with zero placed buildings, zero roads, and zero population. Legacy/developed saves are preserved. The old P6-H auto-bootstrap explicitly yields to the R4 manual-start marker.

The first city prompt asks the player to earn starter resources through a real interview coding mission. After a qualifying learning-resource reward, the prompt changes to construction mode and opens the existing building catalog/placement system.

## Reused systems

R4 deliberately reuses the already-built systems rather than duplicating them:

- P2 learning resources and anti-grind economy
- building catalog and resource costs
- isometric placement preview from R2
- R3 construction-stage artwork
- building management for upgrade/move/demolish
- roads and later infrastructure planning

## Acceptance

A fresh player can experience: empty land → choose Earn starter resources → coding workspace → successful learning reward → Build → select structure → isometric placement → visible construction stages.

Existing saves with demonstrated learning progress are not wiped or reset.
