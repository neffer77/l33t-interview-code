# Phase 36 — NPC Relationships, Team Dynamics, and Mentorship

Phase 36 upgrades Codeopolis' existing character XP into a persistent relationship network tied to demonstrated engineering evidence.

## Relationship tiers

Characters progress through:

- New Contact
- Working Rapport
- Trusted Partner
- Core Ally
- Long-Term Mentor

## Evidence-driven bonds

Each recurring character responds to evidence that matches their role. Examples:

- Maya Chen: mastery, retention, technical reasoning
- Theo Brooks: repository reviews, projects, debugging, incidents
- Luna Alvarez: mastery, retention, project experimentation
- Marcus Reed: behavioral practice, Interview Day, leadership
- Jin Park: system design, incidents, reviews, projects
- Ada Vale: Interview Day, leadership, campaigns, civilization legacy

The network migrates legacy relationship XP where available.

## Unlocked support

Higher relationship tiers expose role-specific support such as Pattern Clinic, Failure Mode Review, Architecture Review, Story Rehearsal, or Career Strategy. These are narrative/coaching affordances only.

## Authority boundary

Relationships never:

- change hidden tests;
- increase rubric scores;
- alter Interview Day calibration;
- grant mastery or retention evidence;
- create offers or promotions;
- bypass career gates.

This keeps relationships motivating without turning friendship into a scoring exploit.

## Integration

Phase 36 listens to existing authoritative events from coding, retention, reasoning, debugging, incidents, design, behavioral practice, Interview Day, leadership, campaigns, repository reviews, projects, and civilization legacy. Relationship tier changes emit telemetry and positive visual feedback.
