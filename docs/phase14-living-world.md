# Phase 14 — Living World & Campaigns

Phase 14 composes Codeopolis's existing judged coding, engineering incident, system-design, career, rival-organization, city, and mastery systems into a persistent external world.

## Core loop

World changes → choose a campaign or optional event → complete real engineering work → make strategic choices → alter organization influence → finish a capstone → place a campaign landmark → preserve the outcome in world history.

## Major campaigns

1. **Global Autonomous Transit** — Nova Robotics; graphs/search; awards the Global Transit Nexus.
2. **Planetary Cloud Migration** — Atlas Cloud; structures/graphs/search; awards the Planetary Cloud Spire.
3. **AI Research Race** — Helix AI; DP/arrays/search; awards the Frontier AI Campus.
4. **Zero-Day Response** — Vector Security; hashing/search/graphs; awards the Global Security Vault.
5. **Orbital Compute Network** — Orbital Systems; graphs/DP/structures; awards the Orbital Compute Array.

Each campaign uses five stages: adaptive judged coding, a multi-step production incident, a strategic architecture/doctrine decision, an existing scored system-design lab, and a judged capstone.

## Adaptive mission generation

Mission templates are parameterized by organization, domain, failure context, weak district, and an actual challenge from the existing judged bank. Selection favors the weakest relevant retained skill, making the narrative world an adaptive curriculum rather than random flavor text.

## World events

Meaningful engineering actions periodically create optional contextual events such as cloud outages, security alerts, AI breakthroughs, fleet disruptions, and orbital-link degradation. Each event routes to a real weak-skill challenge. Events have no destructive countdown and can be deferred without losing progress.

## World influence

Codeopolis and five rival organizations maintain visible influence. Reputation, campaign outcomes, world-event collaboration, and simulated rival progress move influence over time. The world history records these changes by civilization year.

## Strategic choices

Campaign decisions are persistent. They change world influence and apply modest economy biases in later play, creating consequences without making one choice permanently optimal.

## Learning invariant

Clicks cannot complete a campaign. Coding stages require hidden-test mastery, incident stages require the existing diagnosis/repair/engineering/postmortem chain, and design stages require a passing architecture score. The spectacle follows demonstrated engineering work.
